Dashed horizontal lines are the severity bands; vertical lines mark a detection. Slap the machine and watch where the spike lands relative to the bands — that is what the sensitivity slider moves.

Higher catches gentler taps and more desk bumps.

Minimum gap between detections. One slap rings the chassis for a while; this keeps that from counting twice.

Reads the sensor at 402 Hz instead of 805 Hz, for about half the CPU. Same recall at slightly higher sensitivity, with a few more false positives.

Turn on what a slap should do. Each one you enable gets its own section in the sidebar.

Unlocks running an arbitrary command on every slap. It receives the event as JSON on stdin and as SPANK_* environment variables, so it can do anything you can script — which is also why it is behind this switch.
